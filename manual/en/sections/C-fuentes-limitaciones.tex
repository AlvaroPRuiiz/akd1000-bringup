\chapter{Sources and limitations}
\label{app:fuentes-limitaciones}

The instructions in this manual are based mainly on official BrainChip, Raspberry Pi
and Waveshare documentation, together with the thesis report and files.

The reference environment uses Akida 2.19.1, while the current documentation consulted
for this manual corresponds to MetaTF 2.19.3. Check PCIe driver compatibility before
using later kernel or SDK versions.

This edition has not yet been validated through a complete session with a new user
and physical access to the board. Reproducing the AoA case also requires the original
models and data, which are not part of this release.

Power measurements from the Akida API do not represent total system consumption.
The manual also excludes features such as \emph{edge learning} and Akida Engine.
