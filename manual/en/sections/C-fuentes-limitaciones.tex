\chapter{Sources and limitations}
\label{app:fuentes}

The instructions are based on official BrainChip, Raspberry Pi and Waveshare documentation.
The repository's reference environment uses Akida 2.19.1; the documented MetaTF route
uses 2.19.3. Check driver compatibility against your kernel and SDK.
A complete session with a new user and a physical board remains pending.

API power readings do not measure total system consumption.
The manual does not cover \emph{edge learning} or Akida Engine.

The AoA model-conversion pipeline and its experimental results are documented separately
in \href{https://github.com/AlvaroPRuiiz/akida-model-deployment-pipeline}{\code{akida-model-deployment-pipeline}}.
