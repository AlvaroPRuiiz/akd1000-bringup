\chapter{Fuentes y limitaciones}
\label{app:fuentes}

Las instrucciones se basan en la documentación oficial de BrainChip, Raspberry Pi y Waveshare.
El entorno de referencia del repositorio utiliza Akida 2.19.1; la ruta MetaTF documentada
utiliza 2.19.3. Comprueba la compatibilidad del controlador con tu kernel y SDK.
La ejecución completa del procedimiento con un usuario nuevo y una placa física sigue pendiente.

La potencia disponible por la API no representa el consumo total del sistema.
El manual no cubre funciones como \emph{edge learning} ni Akida Engine.

El pipeline de conversión de modelos AoA y sus resultados experimentales se documentan
por separado en \href{https://github.com/AlvaroPRuiiz/akida-model-deployment-pipeline}{\code{akida-model-deployment-pipeline}}.
