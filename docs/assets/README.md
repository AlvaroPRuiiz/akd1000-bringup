# Fotografías y figuras

En las fotografías con sufijo `-isolated.png` se retiró el entorno original y se dejó un fondo
blanco neutro para centrar la atención en la Raspberry Pi, el carrier y la tarjeta AKD1000.
Una edición de imagen puede alterar detalles pequeños, por lo que ninguna revisión, serigrafía
o conexión se demuestra únicamente con estas imágenes.

La identificación del manual usa el inventario escrito del TFG, las fotografías fuente y las
fichas oficiales citadas. El material conservado no permite atribuir un SKU ni una revisión al
carrier.

Las fotografías originales se conservan en el archivo del TFG del autor; no están incluidas
en este repositorio público. `nine-mode-results.png` procede de los resultados de la memoria.
Cada panel usa su propia escala de color: compara los valores numéricos entre paneles.
